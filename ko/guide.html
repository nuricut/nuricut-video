동영상 압축

바로가기 →
  1. 동영상을 상자에 끌어다 놓거나, 상자를 클릭해서 파일을 고릅니다.
  2. (선택) 구간 자르기로 필요한 부분만 남깁니다. 영상을 멈추고 지금 위치로를 누르면 시작·끝 시간이 입력돼요.
  3. 압축 방식을 고릅니다: 화질로 선택(약하게 / 보통 / 강하게) 또는 목표 용량 맞추기(10MB·25MB·50MB·100MB·직접 입력).
  4. 해상도는 특별한 이유가 없으면 자동으로 두세요. 더 작게 하려면 소리 제거를 체크합니다.
  5. 압축 시작을 누르고, 결과를 확인한 뒤 다운로드를 누릅니다.

💡 팁 디스코드로 보낼 땐 10MB, 메일 첨부는 25MB를 고르세요.

쇼츠 세로 변환

바로가기 →
  1. 가로로 찍은 동영상을 고릅니다.
  2. 미리보기를 보면서 9:16 화면 채우는 방식을 고릅니다: 흐린 배경(전체 보이기), 꽉 채우기(양옆 잘림, 왼쪽/가운데/오른쪽 선택), 검은 여백.
  3. 해상도를 고릅니다: 720×1280은 빠르고, 1080×1920은 더 선명해요.
  4. 필요하면 3분 이내로 구간을 자릅니다.
  5. 세로 영상으로 변환을 누르고, 다운로드한 파일을 유튜브 쇼츠·릴스·틱톡에 올립니다.

💡 팁 사람이 화면 가운데에 있으면 꽉 채우기가 가장 보기 좋아요.

GIF 만들기

바로가기 →
  1. 동영상을 고르면 앞부분 5초가 자동으로 선택됩니다.
  2. 시작·끝 시간을 조절합니다. 15초 이하를 추천해요.
  3. 가로 크기(추천 480px)와 부드러움(추천 15)을 고릅니다.
  4. GIF 만들기를 누르고 결과를 다운로드합니다.

💡 팁 GIF 용량을 줄이려면 구간을 짧게, 가로 크기를 작게, 부드러움을 10으로 하세요.

썸네일 추출

바로가기 →
  1. 동영상을 고르고 이미지 크기(예: 유튜브는 1280×720)와 파일 형식(JPG/PNG)을 고릅니다.
  2. 원하는 장면에서 멈추고 이 장면 캡처를 누르거나, 추천 썸네일 8장을 눌러 선명하고 보기 좋은 장면을 자동으로 받아요.
  3. 버튼을 다시 누르면 앞에서 본 장면과 겹치지 않는 새 추천이 나와요.
  4. 마음에 드는 이미지 아래 저장을 누릅니다.

💡 팁 추천 썸네일은 흐릿하거나 어둡거나 빈 화면을 자동으로 걸러 줘요.

문제가 생겼을 때

영상이 열리지 않거나 미리보기가 안 나와요.

AVI나 일부 MKV는 브라우저가 미리보기를 못 해요. 그래도 압축은 되고, 결과는 어디서나 열리는 MP4로 나옵니다.

멈춘 것 같거나 너무 느려요.

사용자 기기가 직접 처리하기 때문에 길거나 고화질 영상은 시간이 걸려요. 탭을 닫지 말고 화면에 띄워 두세요(최소화하면 느려져요). 해상도를 낮추거나 구간을 자르면 훨씬 빨라집니다.

처리에 실패했어요.

해상도를 낮추거나 구간을 짧게 하고, 다른 무거운 탭을 닫은 뒤 최신 크롬·엣지·파이어폭스·사파리에서 다시 시도해 주세요.

휴대폰에서도 되나요?

네, 됩니다. 다만 긴 영상은 컴퓨터가 훨씬 빨라요.

내 파일은 안전한가요?

네. 파일은 업로드되지 않고 브라우저 안에서만 처리되며, 창을 닫으면 사라집니다.

지원 형식

  • 동영상: MP4, MOV, WebM, AVI, MKV
  • 파일 크기: 약 2.5GB까지
  • 브라우저: 최신 크롬, 엣지, 파이어폭스, 사파리
