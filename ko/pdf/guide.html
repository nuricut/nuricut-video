PDF 합치기

바로가기 →
  1. PDF 여러 개를 상자에 끌어다 놓거나, 상자를 눌러 한꺼번에 고릅니다.
  2. 왼쪽 ⠿ 손잡이를 끌어서 합칠 순서를 정합니다. 빼고 싶은 파일은 ✕를 누르세요.
  3. 빠뜨린 파일은 ＋ 추가로 더 넣을 수 있어요.
  4. PDF 합치기를 누르고 다운로드합니다.

💡 팁 계약서 본문 뒤에 사업자등록증·통장 사본을 붙여 한 파일로 보낼 때 편해요.

PDF 나누기

바로가기 →
  1. 나눌 PDF를 하나 고릅니다. 모든 쪽이 미리보기로 펼쳐져요.
  2. 나누는 방법을 고릅니다: 범위로(예: 1-3, 4-6), 한 쪽씩(쪽마다 파일), 골라 뽑기(원하는 쪽만).
  3. 범위로 나누면 같은 파일로 묶이는 쪽이 같은 색 테두리로 표시돼요.
  4. 나누기를 누르고 다운로드합니다. 파일이 여러 개면 ZIP 하나로 받아요.

💡 팁 "7-"처럼 끝 번호를 비우면 7쪽부터 마지막 쪽까지예요.

페이지 정리

바로가기 →
  1. 정리할 PDF를 고릅니다.
  2. 쪽을 눌러 고른 뒤 왼쪽·오른쪽 회전이나 삭제를 누릅니다. 전체 선택도 있어요.
  3. 쪽을 잡고 끌어서 순서를 바꿉니다. 휴대폰에서는 꾹 누른 뒤 끌어요. 옮기거나 돌리거나 새로 넣은 쪽은 색 테두리와 표시가 붙어요.
  4. 빈 쪽 넣기를 누르면 고른 쪽 뒤(없으면 맨 끝)에 빈 쪽이 들어가요.
  5. PDF 저장을 누르고 다운로드합니다.

💡 팁 스캔하다 거꾸로 들어간 쪽은 오른쪽 회전을 두 번 누르면 바로잡혀요.

이미지 → PDF

바로가기 →
  1. 사진(JPG·PNG·WebP·GIF)을 여러 장 고릅니다.
  2. ⠿ 손잡이로 쪽 순서를 정합니다.
  3. 용지 크기(A4·사진 크기·레터), 방향, 여백을 고릅니다. 방향을 자동으로 두면 가로 사진은 가로 용지에 들어가요.
  4. PDF 만들기를 누르고 다운로드합니다.

💡 팁 휴대폰으로 찍은 서류 사진을 제출용 PDF로 만들 때 A4 + 여백 좁게를 추천해요.

PDF → 이미지

바로가기 →
  1. 이미지로 바꿀 PDF를 고릅니다.
  2. 저장 형식(JPG는 가볍게, PNG는 선명하게)과 화질(96·150·300dpi)을 고릅니다.
  3. 원하는 쪽만 저장하려면 쪽을 눌러 고르세요. 안 고르면 전체를 저장해요.
  4. 이미지로 저장을 누르고 다운로드합니다. 여러 장이면 ZIP으로 받아요.

💡 팁 인쇄용이면 300dpi, 메신저로 보낼 거면 150dpi가 적당해요.

문제가 생겼을 때

PDF가 열리지 않아요.

암호가 걸린 PDF는 아직 열 수 없어요. 손상된 파일일 수도 있으니 다른 프로그램에서 열리는지 확인해 주세요.

쪽이 많으면 느려요.

사용자 기기가 직접 처리하기 때문에 수백 쪽짜리는 미리보기를 그리는 데 시간이 걸려요. 탭을 닫지 말고 기다려 주세요.

다른 도구로 넘어가면 파일이 그대로 있어요.

도구를 옮겨 다니며 이어서 작업할 수 있도록 이 브라우저 안에만 잠시 기억해 둔 거예요. 서버로는 가지 않고, "비우기"나 "다른 파일"을 누르면 지워져요.

휴대폰에서도 되나요?

네, 됩니다. 쪽 순서는 쪽을 꾹 누른 채 끌어서 바꿀 수 있어요.
