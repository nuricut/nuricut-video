nuricut.video の使い方

すべてのツールは同じ手順で使えます。1分で覚えられます。

  1. 1動画を選ぶ
  2. 2オプションを選ぶ
  3. 3スタートを押す
  4. 4結果をダウンロード
🗜️動画圧縮📱縦型ショート動画🎞️GIF作成🖼️サムネイル抽出

🗜️ 動画圧縮

ツールへ移動 →
  1. 動画をボックスにドロップするか、ボックスをクリックしてファイルを選びます。
  2. （任意）トリミングで必要な部分だけを残します。動画を一時停止して現在の位置にするを押すと、開始・終了時間が入力されます。
  3. 圧縮方法を選びます：画質で選ぶ（弱め / 標準 / 強め）または目標サイズに合わせる（10MB・25MB・50MB・100MB・カスタム）。
  4. 解像度は特に理由がなければ自動のままにします。さらに小さくするには音声を削除にチェックします。
  5. 圧縮するを押し、結果を確認してダウンロードを押します。

💡 ヒント Discordに送るなら10MB、メールに添付するなら25MBを選びましょう。

📱 縦型ショート動画

ツールへ移動 →
  1. 横向きの動画を選びます。
  2. プレビューを見ながら9:16画面の埋め方を選びます：ぼかし背景（全体を表示）、フィル（左右をカット、左/中央/右を選択）、黒帯。
  3. 解像度を選びます：720×1280は速く、1080×1920はより鮮明です。
  4. 必要に応じて3分以内にトリミングします。
  5. 縦型動画に変換を押し、ダウンロードしたファイルをYouTubeショート・リール・TikTokにアップロードします。

💡 ヒント 人物が画面の中央にいる場合はフィルが最もきれいです。

🎞️ GIF作成

ツールへ移動 →
  1. 動画を選ぶと、最初の5秒が自動で選択されます。
  2. 開始・終了時間を調整します。15秒以下がおすすめです。
  3. 横幅（おすすめ480px）となめらかさ（おすすめ15）を選びます。
  4. GIFを作成を押して結果をダウンロードします。

💡 ヒント GIFを小さくするには、範囲を短く、横幅を小さく、なめらかさを10にしましょう。

🖼️ サムネイル抽出

ツールへ移動 →
  1. 動画を選び、画像サイズ（例：YouTubeなら1280×720）とファイル形式（JPG/PNG）を選びます。
  2. お気に入りの場面で一時停止してこの場面をキャプチャを押すか、おすすめ8枚を押して鮮明で見栄えの良い場面を自動で取得します。
  3. もう一度押すと、これまでと重ならない新しいおすすめが表示されます。
  4. 残したい画像の下にある保存を押します。

💡 ヒント おすすめ機能は、ぼやけた場面・暗い場面・何も映っていない画面を自動で除外します。

困ったときは

動画が開けない・プレビューが出ない。

AVIや一部のMKVはブラウザでプレビューできませんが、圧縮は可能です。結果はどこでも再生できるMP4になります。

止まっているように見える・とても遅い。

お使いのデバイスで処理するため、長い動画や高画質の動画は時間がかかります。タブを閉じずに画面に表示したままにしてください（最小化すると遅くなります）。解像度を下げるかトリミングするとずっと速くなります。

処理に失敗しました。

解像度を下げるか範囲を短くし、ほかの重いタブを閉じてから、最新のChrome・Edge・Firefox・Safariでもう一度お試しください。

スマホでも使えますか？

はい、使えます。ただし長い動画はパソコンのほうがずっと速いです。

ファイルは安全ですか？

はい。ファイルはアップロードされず、ブラウザ内だけで処理され、ページを閉じると消えます。

対応形式

  • 動画：MP4、MOV、WebM、AVI、MKV
  • ファイルサイズ：約2.5GBまで
  • ブラウザ：最新のChrome、Edge、Firefox、Safari
