nuricut.video PDF の使い方

すべてのPDFツールは同じ手順で使えます。上のタブでツールを切り替えながら、同じファイルで作業を続けることもできます。

  1. STEP 1ファイルを追加
  2. STEP 2オプションを選ぶ
  3. STEP 3スタートを押す
  4. STEP 4ダウンロード

PDF結合

開く →
  1. 複数のPDFを枠にドラッグするか、枠をクリックしてまとめて選びます。
  2. 左の⠿ ハンドルをドラッグして結合の順番を決めます。外したいファイルは✕を押します。
  3. 入れ忘れたファイルは＋ 追加で追加できます。
  4. PDFを結合を押してダウンロードします。

💡 ヒント 契約書の本文と添付書類を1つのファイルにまとめて送るときに便利です。

PDF分割

開く →
  1. 分割するPDFを1つ選びます。すべてのページがプレビューで表示されます。
  2. 分割方法を選びます：範囲で（例：1-3, 4-6）、1ページずつ（ページごとにファイル）、選んで抽出（必要なページだけ）。
  3. 範囲で分割すると、同じファイルにまとまるページが同じ色の枠で表示されます。
  4. 分割を押してダウンロードします。複数ファイルはZIP1つで保存されます。

💡 ヒント 「7-」のように終わりを空けると、7ページ目から最後のページまでになります。

ページ整理

開く →
  1. 整理するPDFを選びます。
  2. ページをタップして選び、左・右に回転または削除を押します。すべて選択もあります。
  3. ページをドラッグして順番を変えます。スマホでは長押ししてからドラッグします。移動・回転・追加したページには色付きの枠とラベルが付きます。
  4. 白紙を追加を押すと、選んだページの後ろ（選んでいなければ最後）に白紙が入ります。
  5. PDFを保存を押してダウンロードします。

💡 ヒント スキャンで逆さまになったページは、右に回転を2回押すと直ります。

画像→PDF

開く →
  1. 写真（JPG・PNG・WebP・GIF）を複数選びます。
  2. ⠿ ハンドルでページの順番を決めます。
  3. 用紙サイズ（A4・写真サイズ・レター）、向き、余白を選びます。向きを自動にすると、横長の写真は横向きの用紙に入ります。
  4. PDFを作成を押してダウンロードします。

💡 ヒント スマホで撮った書類の写真を提出用PDFにするなら、A4＋余白狭いがおすすめです。

PDF→画像

開く →
  1. 画像にするPDFを選びます。
  2. 保存形式（JPGは軽く、PNGは鮮明）と画質（96・150・300dpi）を選びます。
  3. 一部のページだけ保存するときは、そのページをタップして選びます。選ばなければ全ページを保存します。
  4. 画像で保存を押してダウンロードします。複数枚はZIPで保存されます。

💡 ヒント 印刷用なら300dpi、チャットで送るなら150dpiが目安です。

テキスト抽出

開く →
  1. 文字を抜き出すPDFを選びます。
  2. 一部のページだけ抜き出すときは、ページをタップして選びます。選ばなければ全ページから抜き出します。
  3. テキストを抽出を押すと画面に結果が出ます。すべてコピーですぐ貼り付けるか、ダウンロードでTXTファイルを保存します。

💡 ヒント スキャンした紙の文書など、文字が画像になっているPDFからは抜き出せません。

ページ番号

開く →
  1. ページ番号を入れるPDFを選びます。
  2. 位置（6か所）、形式（1 / 1 / 10 / - 1 -）、開始番号、文字サイズを選びます。プレビューにすぐ反映されます。
  3. 表紙がある場合は1ページ目には番号を入れないをオンにします。
  4. ページ番号を入れるを押してダウンロードします。

💡 ヒント 本文が3ページ目から始まる場合は、開始番号を変えて合わせられます。

透かし

開く →
  1. 透かしを入れるPDFを選びます。
  2. 文字（例：社外秘、DRAFT）または画像（ロゴ）を選びます。
  3. 色、濃さ、配置（斜め・横・タイル）、サイズを選ぶと、プレビューにすぐ表示されます。
  4. 透かしを入れるを押してダウンロードします。

💡 ヒント コピーや流出を防ぎたい文書には、タイル配置が効果的です。

署名・印鑑

開く →
  1. 署名するPDFを選びます。
  2. 手書きで署名を書くか、画像を読み込むで印鑑・署名の写真を選びます。白い背景は自動で消えます。
  3. 署名するページに移動して＋ このページに入れるを押し、ドラッグで位置を、角のドラッグでサイズを合わせます。
  4. PDFを保存を押してダウンロードします。

💡 ヒント 複数のページの同じ位置に入れるには全ページの同じ位置にを押します。

余白トリミング

開く →
  1. 余白をカットするPDFを選びます。
  2. 自動はページごとに内容ぴったりに、手動は上・下・左・右をmmで決めてカットします。
  3. プレビューで暗い部分がカットされる部分です。
  4. 余白をカットを押してダウンロードします。

💡 ヒント スキャンして枠が広く残った文書をスマホで見るときに特に便利です。

PDF圧縮

開く →
  1. 圧縮するPDFを選びます。
  2. 圧縮の強さを選びます。普通がおすすめです。
  3. さらに小さくしたいときは最大圧縮をオンにします。すべてのページが画像になり、文字は選択できなくなります。
  4. PDFを圧縮を押すと小さくなったサイズが表示され、ダウンロードできます。

💡 ヒント メール添付のサイズ制限に引っかかるときは、まず「普通」で試してください。

文書情報の削除

開く →
  1. 情報を削除するPDFを選びます。
  2. ファイルに入っている作成者、作成ソフト、日付などが表で表示されます。
  3. 文書情報をすべて削除を押してダウンロードします。

💡 ヒント 社外に送る文書に会社PCの名前や作成者が残らないようにするときに使います。

困ったときは

PDFが開けません。

パスワード付きのPDFはまだ開けません。ファイルが破損している可能性もあるので、ほかのアプリで開けるか確認してください。

ページが多いと遅いです。

お使いのデバイスで処理するため、数百ページのファイルはプレビューの表示に時間がかかります。タブを閉じずにお待ちください。

ツールを切り替えてもファイルが残っています。

ツールを続けて使えるよう、このブラウザの中だけに一時的に記憶しています。サーバーには送信されず、「クリア」や「別のファイル」を押すと消去されます。

スマホでも使えますか？

はい、使えます。ページを長押ししてからドラッグすると並べ替えられます。

対応形式

  • PDF：パスワードのない一般的なPDF
  • 画像：JPG、PNG、WebP、GIF
  • ブラウザ：最新のChrome、Edge、Firefox、Safari
