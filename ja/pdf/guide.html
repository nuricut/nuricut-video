nuricut.video PDF の使い方

すべてのPDFツールは同じ手順で使えます。上のタブでツールを切り替えながら、同じファイルで作業を続けることもできます。

  1. STEP 1ファイルを追加
  2. STEP 2オプションを選ぶ
  3. STEP 3スタートを押す
  4. STEP 4ダウンロード

PDF結合

開く →
  1. 複数のPDFを枠にドラッグするか、枠をクリックしてまとめて選びます。
  2. 左の⠿ ハンドルをドラッグして結合の順番を決めます。外したいファイルは✕を押します。
  3. 入れ忘れたファイルは＋ 追加で追加できます。
  4. PDFを結合を押してダウンロードします。

💡 ヒント 契約書の本文と添付書類を1つのファイルにまとめて送るときに便利です。

PDF分割

開く →
  1. 分割するPDFを1つ選びます。すべてのページがプレビューで表示されます。
  2. 分割方法を選びます：範囲で（例：1-3, 4-6）、1ページずつ（ページごとにファイル）、選んで抽出（必要なページだけ）。
  3. 範囲で分割すると、同じファイルにまとまるページが同じ色の枠で表示されます。
  4. 分割を押してダウンロードします。複数ファイルはZIP1つで保存されます。

💡 ヒント 「7-」のように終わりを空けると、7ページ目から最後のページまでになります。

ページ整理

開く →
  1. 整理するPDFを選びます。
  2. ページをタップして選び、左・右に回転または削除を押します。すべて選択もあります。
  3. ページをドラッグして順番を変えます。スマホでは長押ししてからドラッグします。移動・回転・追加したページには色付きの枠とラベルが付きます。
  4. 白紙を追加を押すと、選んだページの後ろ（選んでいなければ最後）に白紙が入ります。
  5. PDFを保存を押してダウンロードします。

💡 ヒント スキャンで逆さまになったページは、右に回転を2回押すと直ります。

画像→PDF

開く →
  1. 写真（JPG・PNG・WebP・GIF）を複数選びます。
  2. ⠿ ハンドルでページの順番を決めます。
  3. 用紙サイズ（A4・写真サイズ・レター）、向き、余白を選びます。向きを自動にすると、横長の写真は横向きの用紙に入ります。
  4. PDFを作成を押してダウンロードします。

💡 ヒント スマホで撮った書類の写真を提出用PDFにするなら、A4＋余白狭いがおすすめです。

PDF→画像

開く →
  1. 画像にするPDFを選びます。
  2. 保存形式（JPGは軽く、PNGは鮮明）と画質（96・150・300dpi）を選びます。
  3. 一部のページだけ保存するときは、そのページをタップして選びます。選ばなければ全ページを保存します。
  4. 画像で保存を押してダウンロードします。複数枚はZIPで保存されます。

💡 ヒント 印刷用なら300dpi、チャットで送るなら150dpiが目安です。

テキスト抽出

開く →
  1. 글자를 뽑을 PDF를 고릅니다.
  2. 원하는 쪽만 뽑으려면 쪽을 눌러 고르세요. 안 고르면 전체를 뽑아요.
  3. 글자 추출하기를 누르면 화면에 결과가 나와요. 전체 복사로 바로 붙여 넣거나 다운로드로 TXT 파일을 받으세요.

💡 ヒント 스캔한 종이 문서처럼 글자가 그림으로 된 PDF는 글자를 뽑을 수 없어요.

ページ番号

開く →
  1. 쪽 번호를 넣을 PDF를 고릅니다.
  2. 위치(6곳), 형식(1 / 1 / 10 / - 1 -), 시작 번호, 글자 크기를 고릅니다. 미리보기에서 바로 확인돼요.
  3. 표지가 있으면 첫 쪽에는 번호 넣지 않기를 켜세요.
  4. 쪽 번호 넣기를 누르고 다운로드합니다.

💡 ヒント 본문이 3쪽부터 시작하면 시작 번호를 바꿔서 맞출 수 있어요.

透かし

開く →
  1. 워터마크를 넣을 PDF를 고릅니다.
  2. 글자(예: 대외비, DRAFT) 또는 이미지(로고)를 고릅니다.
  3. 색, 진하기, 배치(대각선·가로·바둑판), 크기를 고르면 미리보기에 바로 보여요.
  4. 워터마크 넣기를 누르고 다운로드합니다.

💡 ヒント 복사·유출을 막고 싶은 문서는 바둑판 배치가 효과적이에요.

署名・印鑑

開く →
  1. 서명할 PDF를 고릅니다.
  2. 직접 그리기로 서명을 그리거나, 이미지 불러오기로 도장·서명 사진을 고릅니다. 흰 배경은 자동으로 지워져요.
  3. 서명할 쪽으로 이동해 ＋ 이 쪽에 넣기를 누르고, 끌어서 위치를, 모서리를 끌어서 크기를 맞춥니다.
  4. PDF 저장을 누르고 다운로드합니다.

💡 ヒント 여러 쪽에 같은 위치로 넣으려면 모든 쪽 같은 위치에를 누르세요.

余白トリミング

開く →
  1. 여백을 자를 PDF를 고릅니다.
  2. 자동은 쪽마다 내용에 딱 맞게, 직접은 위·아래·왼쪽·오른쪽을 mm로 정해서 잘라요.
  3. 미리보기에서 어두운 부분이 잘려 나가는 부분이에요.
  4. 여백 자르기를 누르고 다운로드합니다.

💡 ヒント 스캔해서 테두리가 넓게 남은 문서를 휴대폰으로 볼 때 특히 좋아요.

PDF圧縮

開く →
  1. 용량을 줄일 PDF를 고릅니다.
  2. 압축 강도를 고릅니다. 보통 보통을 추천해요.
  3. 더 줄여야 하면 최대 압축을 켜세요. 쪽 전체가 이미지가 되어 글자 선택은 안 돼요.
  4. 용량 줄이기를 누르면 줄어든 크기가 표시되고, 다운로드할 수 있어요.

💡 ヒント 메일 첨부 용량 제한에 걸릴 때 먼저 보통으로 줄여 보세요.

文書情報の削除

開く →
  1. 정보를 지울 PDF를 고릅니다.
  2. 파일 속에 들어 있는 작성자, 만든 프로그램, 날짜 등이 표로 보여요.
  3. 문서 정보 모두 지우기를 누르고 다운로드합니다.

💡 ヒント 외부에 보내는 문서에 회사 PC 이름이나 작성자가 남지 않게 할 때 써요.

困ったときは

PDFが開けません。

パスワード付きのPDFはまだ開けません。ファイルが破損している可能性もあるので、ほかのアプリで開けるか確認してください。

ページが多いと遅いです。

お使いのデバイスで処理するため、数百ページのファイルはプレビューの表示に時間がかかります。タブを閉じずにお待ちください。

ツールを切り替えてもファイルが残っています。

ツールを続けて使えるよう、このブラウザの中だけに一時的に記憶しています。サーバーには送信されず、「クリア」や「別のファイル」を押すと消去されます。

スマホでも使えますか？

はい、使えます。ページを長押ししてからドラッグすると並べ替えられます。

対応形式

  • PDF：パスワードのない一般的なPDF
  • 画像：JPG、PNG、WebP、GIF
  • ブラウザ：最新のChrome、Edge、Firefox、Safari
