合并 PDF

前往 →
  1. 将多个 PDF 拖到框中，或点击框一次选择多个。
  2. 拖动左侧的 ⠿ 手柄调整合并顺序。要移除文件请点击 ✕。
  3. 漏掉的文件可以用 ＋ 添加继续加入。
  4. 点击 合并 PDF，然后下载。

💡 提示 把合同正文和附件合成一个文件发送时很方便。

拆分 PDF

前往 →
  1. 选择要拆分的 PDF，所有页面会以预览方式显示。
  2. 选择拆分方式：按范围（例：1-3, 4-6）、逐页（每页一个文件）或挑选页面（只要需要的页）。
  3. 按范围拆分时，进入同一文件的页面会显示相同颜色的边框。
  4. 点击拆分并下载。多个文件会打包为一个 ZIP。

💡 提示 像 "7-" 这样不写结束页，表示从第 7 页到最后一页。

整理页面

前往 →
  1. 选择要整理的 PDF。
  2. 点击页面选择后，按向左/向右旋转或删除。也可以全选。
  3. 拖动页面调整顺序。手机上请先长按再拖动。移动、旋转或新插入的页面会显示彩色边框和标记。
  4. 插入空白页会在所选页面之后（未选择时在最后）插入空白页。
  5. 点击保存 PDF并下载。

💡 提示 扫描时倒过来的页面，点两次向右旋转即可纠正。

图片转 PDF

前往 →
  1. 选择多张照片（JPG、PNG、WebP、GIF）。
  2. 用 ⠿ 手柄调整页面顺序。
  3. 选择纸张大小（A4、照片尺寸、Letter）、方向和边距。方向设为自动时，横向照片会放在横向页面上。
  4. 点击生成 PDF并下载。

💡 提示 把手机拍的文件照片做成提交用 PDF 时，推荐 A4 + 窄边距。

PDF 转图片

前往 →
  1. 选择要转成图片的 PDF。
  2. 选择保存格式（JPG 体积小，PNG 更清晰）和画质（96、150、300dpi）。
  3. 只想保存部分页面时，点击选择这些页面。不选择则保存全部。
  4. 点击保存为图片并下载。多张图片会打包为 ZIP。

💡 提示 打印用 300dpi，发聊天软件用 150dpi 就够了。

遇到问题时

PDF 打不开。

暂时无法打开加密的 PDF。文件也可能已损坏，请确认它能否在其他软件中打开。

页数多时很慢。

处理由您的设备完成，几百页的文件需要一些时间来绘制预览。请保持标签页打开并稍等。

切换工具后文件还在。

为了方便您在工具之间连续使用，文件只会暂时保存在此浏览器中。它不会发送到服务器，点击"清空"或"其他文件"即可删除。

手机上能用吗？

可以。长按页面后拖动即可调整顺序。

支持的格式

  • PDF：未加密的普通 PDF
  • 图片：JPG、PNG、WebP、GIF
  • 浏览器：最新版 Chrome、Edge、Firefox、Safari
