nuricut.video PDF 使用方法

所有 PDF 工具的使用步骤都相同。还可以通过上方标签在工具之间切换，继续处理同一个文件。

  2. STEP 2选择选项
  3. STEP 3点击开始
  4. STEP 4下载结果

合并 PDF

前往 →
  1. 将多个 PDF 拖到框中，或点击框一次选择多个。
  2. 拖动左侧的 ⠿ 手柄调整合并顺序。要移除文件请点击 ✕。
  3. 漏掉的文件可以用 ＋ 添加继续加入。
  4. 点击 合并 PDF，然后下载。

💡 提示 把合同正文和附件合成一个文件发送时很方便。

拆分 PDF

前往 →
  1. 选择要拆分的 PDF，所有页面会以预览方式显示。
  2. 选择拆分方式：按范围（例：1-3, 4-6）、逐页（每页一个文件）或挑选页面（只要需要的页）。
  3. 按范围拆分时，进入同一文件的页面会显示相同颜色的边框。
  4. 点击拆分并下载。多个文件会打包为一个 ZIP。

💡 提示 像 "7-" 这样不写结束页，表示从第 7 页到最后一页。

整理页面

前往 →
  1. 选择要整理的 PDF。
  2. 点击页面选择后，按向左/向右旋转或删除。也可以全选。
  3. 拖动页面调整顺序。手机上请先长按再拖动。移动、旋转或新插入的页面会显示彩色边框和标记。
  4. 插入空白页会在所选页面之后（未选择时在最后）插入空白页。
  5. 点击保存 PDF并下载。

💡 提示 扫描时倒过来的页面，点两次向右旋转即可纠正。

图片转 PDF

前往 →
  1. 选择多张照片（JPG、PNG、WebP、GIF）。
  2. 用 ⠿ 手柄调整页面顺序。
  3. 选择纸张大小（A4、照片尺寸、Letter）、方向和边距。方向设为自动时，横向照片会放在横向页面上。
  4. 点击生成 PDF并下载。

💡 提示 把手机拍的文件照片做成提交用 PDF 时，推荐 A4 + 窄边距。

PDF 转图片

前往 →
  1. 选择要转成图片的 PDF。
  2. 选择保存格式（JPG 体积小，PNG 更清晰）和画质（96、150、300dpi）。
  3. 只想保存部分页面时，点击选择这些页面。不选择则保存全部。
  4. 点击保存为图片并下载。多张图片会打包为 ZIP。

💡 提示 打印用 300dpi，发聊天软件用 150dpi 就够了。

提取文字

前往 →
  1. 选择要提取文字的 PDF。
  2. 只想提取部分页面时，点击选择页面。不选则提取全部。
  3. 点击提取文字，结果会显示在屏幕上。用全部复制直接粘贴，或用下载保存为 TXT 文件。

💡 提示 扫描的纸质文档等文字是图片的 PDF 无法提取文字。

添加页码

前往 →
  1. 选择要添加页码的 PDF。
  2. 选择位置（6 处）、样式（1 / 1 / 10 / - 1 -）、起始页码和字号，预览会立即更新。
  3. 有封面时，请打开第一页不加页码。
  4. 点击添加页码并下载。

💡 提示 正文从第 3 页开始时，可以修改起始页码来对应。

水印

前往 →
  1. 选择要加水印的 PDF。
  2. 选择文字（如：机密、DRAFT）或图片（标志）。
  3. 选择颜色、浓度、排列（斜向・横向・平铺）和大小，预览会立即显示。
  4. 点击添加水印并下载。

💡 提示 想防止复制或外泄的文档，使用平铺排列效果最好。

签名·印章

前往 →
  1. 选择要签名的 PDF。
  2. 用手写写下签名，或用导入图片选择印章・签名照片。白色背景会自动去除。
  3. 翻到要签名的页面，点击＋ 放到这一页，拖动调整位置，拖动角落调整大小。
  4. 点击保存 PDF并下载。

💡 提示 想在多页的同一位置放置时，请点击所有页同一位置。

裁剪边距

前往 →
  1. 选择要裁剪边距的 PDF。
  2. 自动按每页内容紧密裁剪，手动按设定的毫米数裁掉上下左右。
  3. 预览中暗色的部分就是会被裁掉的部分。
  4. 点击裁剪页边距并下载。

💡 提示 用手机查看边框很宽的扫描文档时特别好用。

压缩 PDF

前往 →
  1. 选择要压缩的 PDF。
  2. 选择压缩强度，推荐使用中。
  3. 需要更小时请打开最大压缩。每页都会变成图片，文字将无法选择。
  4. 点击压缩 PDF，会显示压缩后的大小，然后即可下载。

💡 提示 邮件附件超过大小限制时，先试试"中"。

删除文档信息

前往 →
  1. 选择要删除信息的 PDF。
  2. 文件中保存的作者、制作软件、日期等信息会以表格显示。
  3. 点击删除全部文档信息并下载。

💡 提示 用于避免对外发送的文档中留下公司电脑名或作者名。

遇到问题时

PDF 打不开。

暂时无法打开加密的 PDF。文件也可能已损坏，请确认它能否在其他软件中打开。

页数多时很慢。

处理由您的设备完成，几百页的文件需要一些时间来绘制预览。请保持标签页打开并稍等。

切换工具后文件还在。

为了方便您在工具之间连续使用，文件只会暂时保存在此浏览器中。它不会发送到服务器，点击"清空"或"其他文件"即可删除。

手机上能用吗？

可以。长按页面后拖动即可调整顺序。

支持的格式

  • PDF：未加密的普通 PDF
  • 图片：JPG、PNG、WebP、GIF
  • 浏览器：最新版 Chrome、Edge、Firefox、Safari
