nuricut.video 使用方法

所有工具的使用步骤都一样，一分钟就能学会。

  1. 1选择视频
  2. 2设置选项
  3. 3点击开始
  4. 4下载结果

🗜️ 视频压缩

立即前往 →
  1. 将视频拖到框中，或点击框选择文件。
  2. （可选）用剪辑只保留需要的部分——暂停视频后点击设为当前时间即可设置开始和结束时间。
  3. 选择压缩方式：按画质（轻度 / 中等 / 强力）或目标文件大小（10MB、25MB、50MB、100MB 或自定义）。
  4. 如无特殊需要，分辨率保持自动即可。勾选去除音频可让文件更小。
  5. 点击开始压缩，确认结果后点击下载。

💡 提示 发送到 Discord 选 10MB，作为邮件附件选 25MB。

📱 竖屏短视频

立即前往 →
  1. 选择一个横屏视频。
  2. 一边看预览一边选择 9:16 画面的填充方式：模糊背景（完整显示）、铺满（裁掉两侧，可选左/中/右）或黑边。
  3. 选择分辨率：720×1280 更快，1080×1920 更清晰。
  4. 如有需要，将视频剪辑到 3 分钟以内。
  5. 点击转换为竖屏视频，下载后上传到 YouTube Shorts、Reels 或 TikTok。

💡 提示 人物在画面中央时，铺满通常效果最好。

🎞️ 制作GIF

立即前往 →
  1. 选择视频后会自动选中前 5 秒。
  2. 调整片段的开始和结束时间，建议不超过 15 秒。
  3. 选择宽度（推荐 480px）和流畅度（推荐 15）。
  4. 点击制作GIF并下载结果。

💡 提示 想让 GIF 更小：缩短片段、减小宽度、流畅度设为 10。

🖼️ 提取封面

立即前往 →
  1. 选择视频，并选择图片尺寸（如 YouTube 用 1280×720）和格式（JPG 或 PNG）。
  2. 在喜欢的画面暂停并点击截取当前画面，或点击智能推荐8张自动获取清晰好看的画面。
  3. 再次点击会得到不与之前重复的新推荐。
  4. 在想保留的图片下方点击保存。

💡 提示 智能推荐会自动跳过模糊、过暗和空白的画面。

遇到问题时

视频无法打开或无法预览。

AVI 和部分 MKV 等格式浏览器无法预览，但仍然可以压缩，结果是在任何设备上都能播放的 MP4。

好像卡住了或非常慢。

处理由您自己的设备完成，较长或高分辨率的视频需要时间。请保持页面打开并显示在前台（最小化后会变慢）。降低分辨率或剪辑会快很多。

处理失败。

请降低分辨率或缩短片段，关闭其他占用资源的标签页，并使用最新版 Chrome、Edge、Firefox 或 Safari 重试。

手机上能用吗？

可以。不过较长的视频用电脑处理会快很多。

我的文件安全吗？

安全。文件绝不会上传，所有处理都在浏览器中完成，关闭页面后就会消失。

支持的格式

  • 视频：MP4、MOV、WebM、AVI、MKV
  • 文件大小：最大约 2.5GB
  • 浏览器：最新版 Chrome、Edge、Firefox、Safari
