How to use nuricut.video PDF

Every PDF tool works the same way. You can also hop between tools with the tabs at the top and keep working on the same file.

  1. STEP 1Add files
  2. STEP 2Pick options
  3. STEP 3Press start
  4. STEP 4Download

Merge PDF

Open →
  1. Drop several PDFs into the box, or click the box to choose them all at once.
  2. Drag the ⠿ handle on the left to set the order. Press ✕ to remove a file.
  3. Forgot one? Add more with ＋ Add.
  4. Press Merge PDFs, then Download.

💡 Tip Handy for sending a contract together with its attachments as a single file.

Split PDF

Open →
  1. Choose the PDF to split. Every page is shown as a preview.
  2. Pick how to split: By range (e.g. 1-3, 4-6), Every page (one file per page) or Pick pages (only the ones you want).
  3. When splitting by range, pages that go into the same file share the same border color.
  4. Press Split and download. Several files come as one ZIP.

💡 Tip Leave the end blank, like "7-", to go from page 7 to the last page.

Organize pages

Open →
  1. Choose the PDF to organize.
  2. Tap pages to select them, then press Rotate left/right or Delete. There is Select all too.
  3. Drag a page to change the order. On phones, press and hold first. Moved, rotated and new pages get a colored border and a label.
  4. Add blank page inserts a blank page after the selected page (or at the end).
  5. Press Save PDF and download.

💡 Tip A page scanned upside down is fixed by pressing Rotate right twice.

Images to PDF

Open →
  1. Choose several photos (JPG, PNG, WebP, GIF).
  2. Set the page order with the ⠿ handle.
  3. Choose the page size (A4, Photo size or Letter), orientation and margin. With Auto, landscape photos get landscape pages.
  4. Press Create PDF and download.

💡 Tip For document photos taken with a phone, A4 with a small margin works well.

PDF to images

Open →
  1. Choose the PDF to turn into images.
  2. Pick the format (JPG is smaller, PNG is sharper) and quality (96, 150 or 300 dpi).
  3. To save only some pages, tap them. Select none to save every page.
  4. Press Save as images and download. Several images come as one ZIP.

💡 Tip Use 300 dpi for printing and 150 dpi for sharing in chats.

Extract text

Open →
  1. 글자를 뽑을 PDF를 고릅니다.
  2. 원하는 쪽만 뽑으려면 쪽을 눌러 고르세요. 안 고르면 전체를 뽑아요.
  3. 글자 추출하기를 누르면 화면에 결과가 나와요. 전체 복사로 바로 붙여 넣거나 다운로드로 TXT 파일을 받으세요.

💡 Tip 스캔한 종이 문서처럼 글자가 그림으로 된 PDF는 글자를 뽑을 수 없어요.

Page numbers

Open →
  1. 쪽 번호를 넣을 PDF를 고릅니다.
  2. 위치(6곳), 형식(1 / 1 / 10 / - 1 -), 시작 번호, 글자 크기를 고릅니다. 미리보기에서 바로 확인돼요.
  3. 표지가 있으면 첫 쪽에는 번호 넣지 않기를 켜세요.
  4. 쪽 번호 넣기를 누르고 다운로드합니다.

💡 Tip 본문이 3쪽부터 시작하면 시작 번호를 바꿔서 맞출 수 있어요.

Watermark

Open →
  1. 워터마크를 넣을 PDF를 고릅니다.
  2. 글자(예: 대외비, DRAFT) 또는 이미지(로고)를 고릅니다.
  3. 색, 진하기, 배치(대각선·가로·바둑판), 크기를 고르면 미리보기에 바로 보여요.
  4. 워터마크 넣기를 누르고 다운로드합니다.

💡 Tip 복사·유출을 막고 싶은 문서는 바둑판 배치가 효과적이에요.

Sign & stamp

Open →
  1. 서명할 PDF를 고릅니다.
  2. 직접 그리기로 서명을 그리거나, 이미지 불러오기로 도장·서명 사진을 고릅니다. 흰 배경은 자동으로 지워져요.
  3. 서명할 쪽으로 이동해 ＋ 이 쪽에 넣기를 누르고, 끌어서 위치를, 모서리를 끌어서 크기를 맞춥니다.
  4. PDF 저장을 누르고 다운로드합니다.

💡 Tip 여러 쪽에 같은 위치로 넣으려면 모든 쪽 같은 위치에를 누르세요.

Crop margins

Open →
  1. 여백을 자를 PDF를 고릅니다.
  2. 자동은 쪽마다 내용에 딱 맞게, 직접은 위·아래·왼쪽·오른쪽을 mm로 정해서 잘라요.
  3. 미리보기에서 어두운 부분이 잘려 나가는 부분이에요.
  4. 여백 자르기를 누르고 다운로드합니다.

💡 Tip 스캔해서 테두리가 넓게 남은 문서를 휴대폰으로 볼 때 특히 좋아요.

Compress PDF

Open →
  1. 용량을 줄일 PDF를 고릅니다.
  2. 압축 강도를 고릅니다. 보통 보통을 추천해요.
  3. 더 줄여야 하면 최대 압축을 켜세요. 쪽 전체가 이미지가 되어 글자 선택은 안 돼요.
  4. 용량 줄이기를 누르면 줄어든 크기가 표시되고, 다운로드할 수 있어요.

💡 Tip 메일 첨부 용량 제한에 걸릴 때 먼저 보통으로 줄여 보세요.

Remove metadata

Open →
  1. 정보를 지울 PDF를 고릅니다.
  2. 파일 속에 들어 있는 작성자, 만든 프로그램, 날짜 등이 표로 보여요.
  3. 문서 정보 모두 지우기를 누르고 다운로드합니다.

💡 Tip 외부에 보내는 문서에 회사 PC 이름이나 작성자가 남지 않게 할 때 써요.

Troubleshooting

My PDF won’t open.

Password-protected PDFs can’t be opened yet. The file may also be damaged — check whether it opens in another app.

It’s slow with many pages.

Your own device does the work, so drawing previews for hundreds of pages takes a while. Keep the tab open and wait a moment.

My file is still there when I switch tools.

So you can keep working across tools, the file is remembered only inside this browser. It is never sent to a server, and pressing "Clear" or "Other file" removes it.

Does it work on phones?

Yes. To reorder pages, press and hold a page, then drag it.

Supported formats

  • PDF: regular PDFs without a password
  • Images: JPG, PNG, WebP, GIF
  • Browsers: latest Chrome, Edge, Firefox and Safari
